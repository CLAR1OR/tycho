## Caveat — read before trusting a number

Every economy constant here is a **placeholder** (DoorCore/TownCore/TechCore/
EtchingsCore/AttunementsCore/WeaponCore all say so in their own headers), and the
player policy below is a deliberately blunt caricature, not a skill model. This
tool does NOT predict real playtest pacing. What it measures honestly — because
the math is the game's own pure cores, never re-implemented — is RELATIVE
pressure between resource sinks, whether the ~40-run sample exhausts the sinks
that exist today, and where a sink saturates and starts stockpiling forever.

## Policies (fixed, as shipped)

- **Player policy:** runs 1-3 die at that floor's boss (run 1 dies on floor 1,
  run 2 on floor 2, run 3 on floor 3 — having cleared every earlier room/floor
  normally); run 4 onward is always a full clear (5 floors, final boss, codex
  shard). A blunt early-game ramp, not a skill model.
- **Door policy:** priority echo > dust > ore > gold > reprieve (reprieve is
  never chosen except when it is the offer's only door — the sim never tracks
  HP, so the spec's "reprieve when hurt" clause never fires); peril is never
  avoided (it only ever raises the payout).
- **Spend policy each town visit, in order:** (1) turn in all Knowledge Shards,
  invest all Knowledge into the cheapest available tech node (real prereqs,
  quiz assumed solved); (2) buildings, cheapest next level first; (3) weapon
  flat refines when Ore covers it; (4) Dust — the 5 implemented etchings first
  until maxed, then the 7 attunements.

## Red flags

- **Dust two-sink saturation:** etchings maxed at run 6, attunements maxed at
  run 9 (seed 1001). Every Dust point earned after both sinks are full has NOTHING
  left to buy — final Dust balance at run 40: 1111 (pure stockpile).
- **Gold explodes while Stone stays genuinely scarce — Stone, not Gold, is the
  economy's real bottleneck.** Final gold balance at run 40 (seed 1001): 94112, with
  no sink left once every gold-only purchase is done (no shop exists yet to spend
  surplus gold). Stone tells a different story: only the Quarry produces it, and
  under the cheapest-first spend policy Stone keeps going to the CHEAPEST Stone
  cost first (Farm/Study L2-L3 at 8-30 Stone) rather than being saved toward the
  single priciest item, Town Walls L3 (100 Stone) — which is STILL unbought at
  run 40 (seed 1001 final levels: farm L3, quarry L3, sophias-study L3, town-walls L2; final Stone: 37). That is a genuine finding
  about the current numbers, not a sim bug: a human optimizing by hand would
  likely save toward Walls L3 instead, but nothing in the data currently rewards
  that over spending Stone as soon as it's affordable.
- **Does ~40 runs cover the spend sinks that exist today?** Mostly. Weapons,
  etchings, attunements, and the codex all saturate well before run 40 (see the
  milestones table). Buildings are the exception — see the Stone bottleneck above
  — so 40 runs is NOT enough to exhaust the building sink under this policy, even
  though Gold alone would cover it many times over. The sample is oversized for
  every OTHER sink and undersized for the 14-node tech budget (see the
  extrapolation above) — expected, since most of v1's content doesn't exist as
  data yet.
